# Fixed ternary diagnostics

The coordinates package retains the complete 2,300-hit fixed catalogue and
its finite character and polynomial checks. The same_filter package computes
the iid expectation for the identical full-run mask and the exact signed
continuation budget. These are descriptive diagnostics of the fixed million
supplement, not new prospective tests or a causal explanation of its tail.

From the repository root:

    python3 -B scripts/verify_editorial.py
    python3 -B scripts/verify_editorial.py --catalogue

The second command also compiles the C++17 classifier and replays the full
retained ordinary-position catalogue against archived HITS.csv and SUMMARY.csv.
It reads retained positions; it does not rescan all the character words.
Python runs without optimization so inherited assertion checks remain active.

The curated files exclude the private reports and conversation archives.
Historical run identifiers in scientific inputs are provenance anchors.
Only the classifier location was adapted for repository packaging; scientific
hit lists are unchanged. Source archive identities, original hashes and the
packaging changes are recorded in
[EDITORIAL_PROVENANCE.json](../../docs/EDITORIAL_PROVENANCE.json).
